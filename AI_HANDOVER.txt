一、项目概述
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这是一个基于 Python 的"我的世界"格式转换器, 功能包括:
  - 建筑格式转换 (bdx/litematic/mcstructure/schematic/schem 互转)
  - 音乐格式转换 (midi/nbs 转指令)
  - 优化功能 (fill合并/区块化/自动加进度/掉落保护/生成保护)
  - 批量处理
  - 像素画转换
  - 加密服务 (.baia 格式 + 授权码系统)
  - 图标替换 (自定义 ICO)

技术栈:
  - Python 3.13
  - Tkinter (GUI)
  - PyInstaller (打包 EXE)
  - BDXConverter 1.2.0 (BDX 解析, PyPI 公开库)
  - nbtlib + brotli + numpy (BDXConverter 依赖)
  - 自定义加密引擎 (PBKDF2+SHA256流密码+HMAC)

入口文件: main.py (CLI) / ui/app.py (GUI)
打包配置: mc_converter.spec

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【决策1: BDX 格式真相】
  - BD@ 文件不是加密的! 是 PhoenixBuilder/Eaglercraft 二进制操作流
  - 之前多个 AI 会话都误判为"第三方加密格式无法解析" (错误!)
  - 正确方案: pip install BDXConverter (PyPI 公开库 v1.2.0)
  - BDXConverter 依赖: nbtlib + brotli + numpy
  - BDX 使用游标式布局: 从(0,0,0)开始, AddX/Y/ZValue 移动游标, PlaceBlock 放方块
  - 输出方块名用短名 (如 "bedrock" 不是 "minecraft:bedrock"), 与 Exchange Tool 一致

【决策2: numpy 必须打包】
  - nbtlib 内部用了 numpy, 不能排除
  - mc_converter.spec 的 excludes 列表不能包含 numpy
  - 这导致 EXE 从 22MB 增大到 34.7MB (可接受)

【决策3: 加密服务设计】
  - .baia 格式: 魔数 + 版本 + 元数据JSON + file_id + salt + nonce + 密文 + HMAC
  - 授权码 = 解密密钥 (HMAC 校验隐式验证, 无需买家持有创作者密钥)
  - 授权等级: trial(500方块+水印) / paid(无限) / full(商业授权)
  - 创作者主密钥 = 文件解密密码, 必须妥善保存

【决策4: 图标嵌入方式】
  - 用 PyInstaller 的 icon='app.ico' 参数直接嵌入 (不是后期 PE 替换)
  - app.ico 由 change_icon.py 从 jpg 生成 (6个尺寸: 256/128/64/48/32/16)
  - 如图标不显示: 重启资源管理器或重启电脑刷新缓存

五、已知坑点 & 排错指南
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. PowerShell 不支持 && 分隔符, 用 ; 代替
2. 沙箱限制无法删除某些文件, 用 Python shutil.rmtree(ignore_errors=True)
3. PyInstaller 打包时设 PYTHONDONTWRITEBYTECODE=1 避免 __pycache__
4. BDXConverter 导入失败 -> 检查 numpy/nbtlib/brotli 是否打包
5. 图标不变化 -> 重启 explorer.exe 或清空 IconCache.db
6. EXE 中相对路径要用 sys._MEIPASS (block_runtime_ids.json 路径)
7. 授权码验证失败 -> 检查 base32 编解码 (24字符=15字节, 前9字节payload+6字节sig)
8. PE 资源修改 -> 必须先备份 overlay, 修改后恢复 (否则 PYZ 被截断)

【排错: BDX 转换为空】
  1. 检查文件是否 BD@ 开头 (用 hex 查看前3字节)
  2. 源码模式测试: python -c "from core.readers import read_structure; print(len(read_structure(path,'bdx').blocks))"
  3. EXE 模式测试: 查看输出 txt 中的错误信息 (现在会显示 traceback)
  4. 常见原因: numpy 未打包 / BDXConverter 版本不对 / 文件损坏
