## 修复 /api/plugin/run "未产生输出文件"（2026-08-14 16:21）
- 用户报：工具箱运行后提示"未产生输出文件, 请检查输入与参数"。根因两处：
  1. 旧逻辑用"文件名差集"(after - before) 判定产物。重复运行同一工具会**覆盖写**同名文件（如 `建筑txt/<base>.txt`），文件名未变 → 被误判为无新文件 → 报错。
  2. 4 个纯文本结果插件（`生成创作者密钥`/`查看机器码`/`重新生成授权码`/`预览.baia元数据`）只返回字符串、不产生文件，旧逻辑一律 500。
- 修复（`web/backend/main.py` 的 `plugin_run`）：
  - 改为 **mtime 判定**（`_scan_new_files` 扫描 `~/Desktop/建筑txt`，取 mtime>=运行开始时间），同时覆盖"新增"与"覆盖写"。
  - 只扫描桌面 `建筑txt` 目录（不扫描任务 work 目录，避免把上传的输入文件当产物返回）。
  - 捕获 stdout（不捕获 stderr，以免污染子进程线程输出）。
  - 插件返回字符串且非文件路径 → 作为 `message` 返回，前端 `<pre>` 展示，不再报错。
  - 响应新增 `message` 字段；前端 `App.jsx` 运行结果区改为：有 message 先显示文本，再列下载文件。
- 验证：本地 8011/8012 端口 + 线上 :8000 均通过（生成创作者密钥返回 message；bdx转txt 连跑两次都出文件；公网 baianb.kdns.fr 仍 200）。
- 部署：编辑后 `rm -rf dist && 用托管 node 重新 vite build`；再重启 uvicorn（杀旧 pid，Start-Process 从项目根 detached 起新进程；隧道 cloudflared 进程不动，自动重连 :8000）。
